# CodeAlpha Python Programming Internship 🚀

This repository contains my Python projects completed during the **CodeAlpha Python Programming Internship**.

## 📌 Project 1: Basic Chatbot 🤖

A simple rule-based chatbot built using Python.

### Features

* Responds to basic greetings
* Responds to simple questions
* Provides its name when asked
* Ends the conversation when the user types `bye`
* Handles unknown inputs

### Concepts Used

* `if-elif-else`
* Functions
* `while` loop
* `input()` and `print()`
* String handling

### How to Run

```bash
python chatbot.py
```

## 🎮 Project 3: Hangman Game

A simple text-based **Hangman game** developed using Python.

### Features

* Randomly selects a word
* Allows the player to guess letters
* Displays correctly guessed letters
* Tracks incorrect guesses
* Prevents repeated guesses
* Shows the final result when the game ends

### Concepts Used

* Lists
* Strings
* `random` module
* `while` loop
* `if-elif-else`
* Functions
* User input

### How to Run

```bash
python hangman.py
```
