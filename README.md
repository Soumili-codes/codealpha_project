# Basic Chatbot 🤖

A simple rule-based chatbot built using Python.

## Features

* Responds to greetings like "hello"
* Responds to "how are you"
* Provides its name when asked
* Ends the conversation when the user types "bye"
* Handles unknown inputs with a default response

## Concepts Used

* `if-elif-else`
* Functions
* `while` loop
* `input()` and `print()`
* String handling

## How to Run

1. Make sure Python is installed.
2. Open the project in VS Code.
3. Run:

```bash
python chatbot.py
```
